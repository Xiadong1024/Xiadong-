霞冬｜個人創作檔案 — 網站使用說明
更新日期：2026-11-10

一、如何在電腦開啟
1. 先在 ZIP 檔按右鍵，選擇「全部解壓縮」。
2. 開啟解壓縮後的 xiadong-website 資料夾。
3. 用 Chrome 或 Edge 開啟 index.html。
4. 五個 HTML、style.css、script.js、favicon.svg 和三張 JPG 請維持在同一資料夾。
這是純 HTML、CSS、JavaScript 網站，不需要安裝 Node.js 或執行建置指令。主要內容不依賴網路字型或外部套件。

二、頁面對照
index.html       首頁：姓名、標語、插畫形象、作品預覽與導覽。
about.html       關於我：自我介紹、學習方向、重視的事與網站學習紀錄。

works.html       學習成果與作品集：三張作品、分類、放大與作品學習紀錄。
contact.html     未來規劃與聯絡：三項行動計畫與示範留言表單。
style.css        五頁共用的深藍星夜與米金色版型、電腦與手機排版。
script.js        手機選單、作品分類、圖片放大、表單預覽等互動。
work1.jpg        暖色角色・動態姿勢。
work2.jpg        Welcome・角色群像。
work3.jpg        UNDERTALE・音樂舞台。
favicon.svg      網站頁籤星芒圖示。

補齊原本未附上的共用 CSS 與 JavaScript。

作品有分類、學習紀錄展開區與放大視窗；可切換上一件／下一件，按 Esc 關閉。
留言表單只在頁面預覽，不寄出、不保存、不連接郵件服務。

contact.html：未來規劃是可調整的草稿，請依自己的目標修改。
目前未提供真實公開信箱或社群，因此未放置範例或虛構聯絡資訊。若希望公開，可自行加入適合公開的信箱或社群連結。

五、保留的本機練習功能
關於我頁面下方可展開「個人化照片」，選擇 JPG、PNG、WebP 圖片（3 MB 以內）。
興趣頁面可以播放自己裝置的音樂；檔案不會上傳，也不會自動播放。
作品頁面下方可展開「新增本機作品練習」，新增練習卡片（單張 2 MB 以內）。
照片和新增的練習只保存在目前瀏覽器，清除網站資料會移除；這些內容不會自動加入 ZIP 或發布到網站。
直接以 file:// 開啟 HTML 時，不同瀏覽器對本機儲存的處理可能不同，跨頁照片同步不能保證；三件正式作品不受影響。
要讓其他人也看見新增作品，請修改 works.html 並放入相應圖片，再重新提供整個資料夾或網站。
